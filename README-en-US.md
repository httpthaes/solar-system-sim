# 🌌 Planetarium

**Interactive solar system developed as a JavaScript study project**

[PT-BR](README.md) | [EN-US](README-en-US.md)

Using an existing visual project as a foundation, I implemented new features and interactions to deepen my JavaScript studies, gaining a better understanding of element behavior and their hierarchies within a page.

Beyond the technical side, I also conducted research to represent celestial bodies using real data, such as the retrograde rotation of Venus and Uranus, astronomical data, and proportions adapted to the project's visual scale.

</div>

---

## 🚀 Features

- Interactive sidebar with information about celestial bodies
- Click events on the Sun, Moon, and planets
- Orbit pause on hover over celestial bodies
- Conditional display of information
- Hover effects on planets
- Refactoring of selectors and CSS organization
- Use of destructuring to improve code readability
- Structuring of celestial body data into arrays of objects
- Bug fixes for interactions and events

---

## 🧠 Concepts Practiced

- DOM Manipulation
- Event Listeners
- Arrays and Objects
- Destructuring
- Code Refactoring
- Data Organization
- CSS Animations and Keyframes
