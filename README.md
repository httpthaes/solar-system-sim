# 🌌 Planetarium

**Sistema solar interativo desenvolvido como projeto de estudo em JavaScript** 

[PT-BR](README.md) | [EN-US](README-en-US.md)

Utilizando como base um projeto visual já existente, implementei novas funcionalidades e interações para aprofundar meus estudos em JavaScript, compreendendo melhor o comportamento dos elementos e suas hierarquias dentro de uma página. 

Além da parte técnica, também realizei pesquisas para representar os astros utilizando informações reais, como rotação retrógrada de Vênus e Urano, dados astronômicos e proporções adaptadas à escala visual do projeto.

</div>

---

## 🚀 Funcionalidades Implementadas

- Sidebar interativa com informações sobre os astros
- Eventos de clique no Sol, Lua e planetas
- Pausa da órbita ao passar o mouse sobre os astros
- Exibição condicional de informações
- Hover effects nos planetas
- Refatoração de seletores e organização do CSS
- Uso de destructuring para melhorar legibilidade do código
- Estruturação dos dados dos astros em arrays de objetos
- Correção de bugs de interação e eventos

> Todo o processo foi documentado nos commits do projeto.

## 🌠 Créditos

Este projeto foi desenvolvido a partir do [SolarView](https://github.com/CogniSolver/solar-system), criado por **Bijay Pandey**.

O projeto original serviu como estrutura inicial para o sistema solar. A partir dessa base, desenvolvi novas funcionalidades, interações e melhorias.
